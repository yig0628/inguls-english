# INGUL’S English · Render에 설치형 웹앱 배포

이 소스는 안드로이드 홈 화면에 설치하는 PWA입니다. 세일즈·마케팅 팀장 코스, T-health Solution 시연, Chemist Warehouse 본사 미팅, 녹음·재생, 기준표 교정, 복습을 포함합니다. 공유 링크를 열면 학습 화면으로 들어갑니다. 학습 기록은 브라우저의 이 주소에 저장됩니다.

제품과 바이어 미팅에 나오는 거래 조건·마진·전국 확대 계획은 영어 연습을 위한 가상 시나리오입니다.

## GitHub와 Render

1. ZIP을 풀고 `yig0628/inguls-english`의 **Add file → Upload files**에서 압축을 푼 폴더의 내용물을 올립니다. `render.yaml`, `package.json`, `src/`, `public/`이 저장소의 최상위에 오게 하고 `main`에 커밋합니다.
2. Render 대시보드의 **New → Blueprint**로 들어가 GitHub와 연결한 뒤 이 저장소의 `main` 브랜치를 선택합니다.
3. `render.yaml`의 무료 웹 서비스 구성을 확인합니다.
4. **Deploy Blueprint** 후 Render가 알려주는 HTTPS 주소를 열면 학습 화면이 나옵니다.
5. Android Chrome에서 이 주소를 처음 열고 메뉴에서 **설치 및 바로가기 만들기 → 설치**를 누릅니다. 이후 홈 화면의 **INGUL ENGLISH** 아이콘으로 엽니다. 첫 녹음 때 마이크 권한 요청이 나오면 허용합니다. Render의 HTTPS 주소를 공유하면, 링크 미리보기를 지원하는 메신저의 공유 카드에 `public/share-cover.png`를 사용합니다.

Blueprint 대신 **New → Web Service**를 사용할 때는 Runtime을 Node, Instance Type을 Free, Build Command를 `npm ci && npm run build`, Start Command를 `npm start`, Health Check Path를 `/healthz`로 설정합니다.

## Sites 기록을 옮기는 방법

기존 Sites의 **문장 보관함 → 기록 내보내기**에서 JSON을 내려받은 다음 새 Render 앱의 **문장 보관함 → 가져오기**에서 선택합니다. 최신 백업은 교정, 연습 완료 이력, 복습 일정과 연습 설정을 함께 옮깁니다. 초기 버전에서 내보낸 기록 JSON도 가져올 수 있습니다.

기기 간 자동 동기화는 별도 데이터베이스가 필요한 기능입니다. 이 패키지는 기기별로 저장하며, 안정적인 백업을 위해 기록 JSON을 보관해 주세요. 앱의 기준표 교정과 브라우저에서의 녹음·재생은 OpenAI API 키 없이 사용할 수 있습니다. 자유 대화는 앱의 연습 지시문을 복사해 ChatGPT에서 진행할 수 있습니다.

## 로컬 실행

Node.js 22.13 이상에서 `npm ci`, `npm run build`, `npm start`를 차례로 실행합니다. 기본 주소는 `http://localhost:4174/`입니다.

## 말하기 도움과 챌린지

**오늘의 학습지**는 한국 시간 오전 9시에 열립니다. 평일에는 실무 7문장과 스몰토크 3문장, 토요일에는 주간 복습 10문장을 제공합니다. 일요일은 휴식일입니다. **암기 모드**에서 영어를 가리고, **오늘 학습 완료**를 누르면 **지난 학습지**로 이동합니다. 학습지 체크 상태는 기기에서 최근 30일간 보관합니다. 문장 보관함의 교정·복습 기록은 별도로 저장됩니다.

역할극의 **답변 힌트**에서 먼저 답변 구조를 보고, 필요하면 모범답안과 음성을 열 수 있습니다. **한국어로 말하고 영어로 바꾸기**는 지원 브라우저에서 한국어 음성을 받아쓰고, 내장 번역이 가능한 기기에서 영어 초안을 제공합니다. 내장 번역을 지원하지 않는 기기에서는 ChatGPT용 요청문을 복사한 후 번역 결과를 답변 칸에 넣을 수 있습니다. 별도 유료 번역 API를 사용하지 않습니다.

상단 종 아이콘에서 **이 기기 알림 켜기 → 허용 → 테스트 알림**으로 기기마다 푸시를 등록합니다. 월~토 오전 9시(한국 시간)에 발송하며 토요일에는 복습 안내를 보냅니다. GitHub 실행 대기에 대비해 09:15·09:35에 재시도하며 발송에 성공한 기기에는 같은 날 중복 발송하지 않습니다. 종 메뉴에서 휴대폰 캘린더 알림과 앱을 열어 둔 동안의 알림음도 사용할 수 있습니다.

예약 푸시를 배포하려면 Render에 이 앱의 전용 PostgreSQL 연결 `PUSH_DATABASE_URL`, VAPID 키 쌍과 발급자 주소(`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`), 32자 이상의 `PUSH_SCHEDULE_TOKEN`을 추가합니다. GitHub Actions 변수 `INGULS_APP_URL`에는 공개 앱 주소를, Actions 시크릿 `PUSH_SCHEDULE_TOKEN`에는 같은 토큰을 저장합니다. **Morning lesson push**를 수동 실행하면 연결을 확인할 수 있습니다. 공개 저장소가 60일간 비활성 상태면 GitHub가 예약 작업을 중지할 수 있습니다.

하루의 학습을 완료하면 +100P, 평일 3일과 토요일 복습 1세트를 완료하면 추가 +150P입니다. 일요일은 연속 기록에서 제외합니다. 1,000P로 영어·한국어 비즈니스 예문 100선 CSV를 한 번 교환하면 다시 다운로드할 수 있습니다. 백업에는 잠금 해제 여부도 포함됩니다.
